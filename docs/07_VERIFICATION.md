## Браузер и локальные серверы

Проверен обычный пациентский сценарий: главная → исследовательский gate → disabled submit до подтверждения → выбран synthetic/прочитаны условия → настоящий ручной Hb 108, F, 42 → sparse-model отчёт с явными ограничениями и draft-фразами. После возврата к форме введённые значения сохранены. Отдельные API-тесты подтверждают очистку, ошибки и удаление серверных записей. Снимок gate: research_gate_verification.jpg.

Три ранее работавших экземпляра перезапущены с новой защитой: default v1 на 8000, robust_v2 на 8001, calibrated_v3 на 8002. Loopback сохранён. Их исторические базы не импортировались/не удалялись. Учётные записи существуют отдельно; они не входят в ZIP.

## Проверка нового архива

Сборщик использует положительный перечень, создаёт HTML всех основных руководств/правовых шаблонов, реестр и FILES_MANIFEST, пишет ZIP, выполняет testzip и сверяет SHA-256 каждой включённой записи. SHA-256 самого ZIP записывается рядом. В ZIP включены только готовые selected weights и агрегированные результаты; training CSV/splits/OOF/raw external и runtime отсутствуют. Код и пояснения обучения сохранены; для нового обучения источник нужен отдельно.

Весь новый ZIP дополнительно распаковывается в временную папку; Python импортирует backend/weights именно из неё. Установленное окружение исходной машины используется для исполнения, не переносится в ZIP. Проверяются действительная модель всех трёх семейств, gate, обе роли, синтетическая панель, оригинальный синтетический PDF через настоящий worker, чужой доступ, удаление и stateless ключ организации. Итог этой проверки сохраняется в archive_verification.json рядом с ZIP и отдельным evidence в deliverables. Функциональные тесты извлечённых исходников запускаются дополнительно; построчные training/external artifact tests корректно пропускаются при отсутствии исключённых ресурсов.

Фактический результат предшествующего распакованного снимка от 05.10.2026 до обновления окна: найдено 151 тестов, 139 прошли, 12 пропущены, ошибок/провалов нет. Два пропуска относятся к не включённым публичным PDF Helix, десять — к исключённым построчным источникам/разбиениям/производным исследования. В рабочем полном проекте все 151 тест выполнялись и прошли. Отдельный smoke прошёл реальный inference v1/v2/v3 и отдельной v4, настоящий синтетический PDF через worker, приватный оригинал/удаление, чужую сессию, stateless API и отзыв ключа. 19 HTML-страниц не имеют несуществующих локальных href/src; START_WINDOWS.bat совпадает с предоставленным исходником побайтово. Результаты и причины каждого пропуска включены в handoff_verification.json; медицинская/юридическая пригодность из этого не следует. После внесения итога в руководства финальный ZIP повторно проходит сверку манифеста и smoke; одинаковость технических исходников с полным тестовым снимком контролируется по хешам.

HTML проверяется на существование локальных ссылок. Ссылки на намеренно исключённые исследования описывают структуру полного workspace, а не обещание включённого файла. Исходные требования/редакционный DOCX копируются без изменения. START_WINDOWS.bat с PYTHONUTF8=1 и CRLF сохранён побайтово относительно приложения пользователя.

## Границы

Не выполнены нативный Windows запуск/ACL/Job Object, Intel/ARM Windows, первая установка на чистой системе, полноценная визуальная проверка каждой страницы/размера, юридическая экспертиза конкретной организации, регистрационные процедуры или независимая клиническая валидация. Mac worker не имеет жёсткой RAM-квоты. Python 3.12.14 старше актуального 3.12.15; launcher предупреждает, производственный runtime требует обновления. Отсутствие известных CVE в 45 PyPI-пакетах не является подтверждением безопасности ОС/интерпретатора/всех JS-зависимостей.

RAM/temp cleanup не уничтожает скачанные файлы, старые DB, swap/backup/печать. Новая программа не является инструментом универсального обезличивания. Неправдивое заявление synthetic/anonymized может привести к фактической обработке реальных сведений; законность источника и режима проверяет ответственный, не одна галочка.
