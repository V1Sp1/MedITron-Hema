Для синтетических сценариев вручную укажите: женский пол, возраст 42.
Первое нажатие распознаёт PDF и открывает форму проверки. Второе создаёт отчёт.
После каждого сценария нажмите «Очистить данные», чтобы начать новую загрузку.

1. Обычная загрузка с разными датами
Выберите одновременно 01_cbc.pdf и 02_iron.pdf.
Ожидается одно наблюдение, два документа, 14 показателей.
Даты забора: 01.10.2026 и 20.09.2026; Hb 108 г/л, ферритин 9 мкг/л.
После проверки формы правило Hb для женского пола покажет признаки анемии.

2. Пересчёт единиц и границы
Загрузите только 03_units_bounds_repeat.pdf.
Hb 13,1 g/dL станет 131 г/л; MMA 300 nmol/L станет 0,3 мкмоль/л;
CRP 0,5 mg/dL станет 5 мг/л.
Ферритин <5 сохранится границей, поле будет пустым.
B6 в ng/mL не переводится в nmol/L; поле останется пустым.
При женском поле правило Hb не покажет анемию. Дефициты не оценены.

3. Повторные результаты
Выберите одновременно 01_cbc.pdf и 03_units_bounds_repeat.pdf.
Оба Hb (108 и 131 г/л) сохранятся в одном наблюдении. Hb в форме будет пустым.
Сервис не выбирает самый новый результат; для расчёта выберите значение вручную.

5. Скан и ограничения OCR

Требуется локальный OCR. Бланк распознаётся неполно; Hb может остаться пустым.
Этот сценарий проверяет предупреждения и необходимость ручных исправлений.
Источник: https://lab4u.ru/store/sample/1142/
