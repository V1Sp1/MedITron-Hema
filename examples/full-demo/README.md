# Полные вымышленные примеры Hema

15 панелей × две роли. Модель: hema-baseline-v1-1dc7ef11da40.

Все значения созданы вручную. Здесь нет исходных записей пациентов.
Отчёты — реальные расчёты модели на этих панелях, а не эталонные диагнозы.
Модель и фразы остаются исследовательскими. Числа 0–1 не являются проверенными вероятностями заболеваний.

1. Откройте сайт → выберите роль → «Посмотреть пример». Все сценарии доступны в списке.
2. Для повторного расчёта импортируйте input_panels.csv и выберите запись. Порядок приведён ниже.
3. reports.json содержит входы, числовые оценки, ограничения и фразы для пациента и врача.
4. Выбор примера не запускает API: показывает сохранённый расчёт. Для повторения с теми же весами нажмите «Рассчитать».
5. Пустые ячейки CSV означают отсутствующий анализ, а не ноль. Единицы — из словаря проекта.

1. Железо: расширенная панель (iron)
2. B12: анемия и расширенная панель (B12)
3. Фолаты: расширенная панель (folate)
4. B6: расширенная панель (B6)
5. Медь: расширенная панель (copper)
6. Железо и B12: сочетание признаков (mixed)
7. Повышенные маркеры воспаления (inflammation)
8. Анемия и изменённые показатели почек (other)
9. Hb выше порога: расширенная панель (normal)
10. B12 при Hb = 120: неоднозначная оценка (B12_boundary)
11. Мужчина, Hb = 130: пограничный случай (male_boundary)
12. Расширенная панель: причина неопределённа (uncertain)
13. Расхождение модели с правилом Hb (conflict)
14. Только общий анализ крови (cbc)
15. Мало данных: только гемоглобин (sparse)

Обновление: .venv/bin/python scripts/build_demo_scenarios.py, затем сборка фронтенда.
